# Автоматизация теста API заказов

## Описание

Автотест проверяет, что после создания заказа его можно получить по трек-номеру.

## Сценарий теста

1. Отправить POST-запрос на создание заказа.
2. Сохранить трек-номер из ответа.
3. Отправить GET-запрос для получения заказа по трек-номеру.
4. Проверить, что GET-запрос возвращает HTTP-статус `200`.

## Файлы проекта

- `configuration.py` — URL тестового стенда и пути API.
- `data.py` — тело запроса для создания заказа.
- `sender_stand_request.py` — функции отправки HTTP-запросов.
- `test_get_order.py` — автотест получения заказа по трек-номеру.
- `.gitignore` — список файлов и папок, исключённых из Git.
- `README.MD` — описание проекта и инструкция по запуску.

## Установка

Необходим установленный Python.

Установить зависимости можно командой:

```bash
py -m pip install pytest requests
```

## Запуск теста

Открой терминал в корневой папке проекта и выполни:

```bash
py -m pytest test_get_order.py -v
```

При успешном прохождении теста в выводе появится статус `PASSED`.

## Серверные логи

Путь к серверному логу ошибок:

`/var/www/backend/logs/error.log`

Этот файл расположен на стороне сервера. Для доступа к нему нужны соответствующие права и доступ к серверной среде.
